How to fix

[A]      Remove the opt-out from the Expo config and rebuild the native project
         1. Delete UIDesignRequiresCompatibility from ios.infoPlist in the Expo config.
         2. Run npx expo prebuild --clean -p ios (or let EAS Build do it) so the generated
            Info.plist no longer has it.
         3. Run the app on an iOS 27 simulator; the other findings in this report are the places to
            look at first.
         https://github.com/muhittincamdali/glassready/blob/main/docs/guides/react-native-expo.md

[B]      Leave the header background to the system on iOS
         1. Set headerStyle.backgroundColor, headerBackground and headerBlurEffect only for Android
            (Platform.select) or for iOS before 26.
         2. Keep the brand colour on headerTintColor.
         https://github.com/muhittincamdali/glassready/blob/main/docs/guides/react-native-expo.md

[C]      Move to Expo Router's native tabs, or keep the JavaScript bar on purpose
         1. For the system tab bar, use NativeTabs from expo-router/native-tabs (SDK 58 and later;
            expo-router/unstable-native-tabs in SDK 54 to 57).
         2. If the custom bar is part of the brand, keep it and check it next to the Liquid Glass
            headers on an iOS 27 simulator.
         https://github.com/muhittincamdali/glassready/blob/main/docs/guides/react-native-expo.md
